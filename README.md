# Love City — World Preview

This is an early playable browser-based 3D environment preview for feedback. It is not the finished realistic game.

## Run
- Open `index.html` in a browser that supports ES modules and WebGL. Internet is needed to load Three.js from jsDelivr.
- Desktop: WASD / arrow keys to move, Shift to run, drag mouse to orbit the camera.
- Touch: use the on-screen joystick; tap RUN to run.

## Current preview
Procedural city blocks, roads, sidewalks, trees, streetlights, a third-person player, simple walking pedestrians, and moving traffic. Geometry and animation are placeholders and need replacement with quality models, proper animation, traffic behavior, collisions, mission systems, and story content.
